# Index (find things here before you search the tree)

Paths are from the repo root. Port code is in `3ds/`. Class E = debug only.

## Port source files (3ds/src)
- `pm_main.c`: boot, frame loop (exact 30 fps pacing, PC01), crash handler, FPS HUD, thread stack records.
- `pm_mem.c`: FCRAM split (4 MB N64 RAM block, resident ROM, linear pool).
- `pm_os.c`: libultra OS calls, message queues, threads, ROM reads (`nuPiReadRom`, remap, packed ROM), flash save.
- `pm_nusys.c`: nuGfx and nuCont calls, pad read, SI no-ops.
- `pm_input.c`: pad mapping, `autoa`, `padscript`, `padrand`, `taptest`, `faulttest`.
- `pm_gbi.c`: Fast3D interpreter (vertex, triangle, matrix, render modes, culling, off-screen targets).
- `pm_comb.c`: RDP colour combiner as PICA texenv stages (S25).
- `pm_gpu.c`: PICA200 state, batches, scissor, fill, off-screen render targets, shots.
- `pm_gu.c`: libultra `gu*` matrix functions.
- `pm_tex.c`: texture decode, tile masks, cache (512 slots), off-screen texture binding.
- `pm_audio.c`: ndsp output and the audio thread hand-over.
- `pm_rsp_audio.c`: C version of the RSP audio microcode operations.
- `pm_map.c`: big-endian fixes for map data, `--wrap` of map load, GotoMap guard, `dma_copy` hook, `load_asset_by_name` wrap.
- `pm_mapdata.c`: restore of map static data at map entry, probe switch `dataprobe` (MS01).
- `map_restore_table.c`: generated by `gen_map_restore.py`.
- `pm_phase.c`: per-frame phase timer (switch `phase`) and the step wrap.
- `pm_log.c`: non-blocking log (ring buffer, writer thread on core 1), switch parser, `pm_debug_has`.
- `pm_warp.c`: warp, presets, story, battle hooks, tour, `ptrcheck`, `sp`, `hp`, smoke.
- `effect_loads.c`: generated C form of the effect load asm.
- `rom_remap.h`: generated list of dropped ROM ranges and swap ranges.
- `game_stubs.c`: `pm_game_bind`, empty N64 shims (Q5). `pm_later.c`: almost empty. `pm_buffers.c`: the buffers gBackgroundImage_buf and pm_world_entity_heap.
- Headers: `3ds/include/` (`pm_port.h`, `pm_gbi.h`, `pm_gpu.h`, `pm_tex.h`, `pm_rsp_audio.h`). Generated headers: `3ds/stub_include/` (below). Shader: `3ds/shaders/pm.v.pica`.

## Tools and scripts (3ds/tools and 3ds)
- `3ds/run_azahar.ps1`: run the 3dsx in Azahar with switches, turbo, smoke, fault stop. Writes `build3ds/last_log.txt` and `build3ds/last_unmapped.txt`.
- `3ds/go.ps1`, `3ds/build.sh`, `3ds/push_3ds.sh`, `3ds/bump_build.cmake`: build and push glue.
- `tools/extract_assets.ps1` and `extract_assets.py`: extract assets from the ROM with splat and write build.ninja.
- `tools/crunch64_shim.py`, `pigment64_shim.py`: stand-ins for Rust CLI tools used by the extraction.
- `tools/gen_map_sources.py`: writes `3ds/maps.cmake` and `3ds/map_syms.lds` from the decomp (skip list `3ds/maps_skip.txt`).
- `tools/gen_map_restore.py`: writes `3ds/ld/map_restore.ld` and `map_restore_table.c`. `learn` adds changers to `3ds/map_restore.txt`.
- `tools/gen_effect_ld.py`: writes `effect_ld_addrs.h` and `effects.cmake`. `gen_battle_ld.py`: writes `battle_ld_addrs.h`. `gen_battle_names.py`: writes `battle_name_table.h`.
- `tools/gen_data_rom.py`: writes `data_rom_addrs.h`. `gen_entity_rom.py`: writes `entity_model_offsets.h`. `gen_msg_ids.py`: writes `include/message_ids.h` (git-ignored). `gen_rom_remap.py`: writes `src/rom_remap.h`.
- `tools/rom_static_check.py`: static check of named ROM ranges against dropped ranges. `rom_symbol_audit.py`: classify every ROM-address symbol.
- `tools/rom_trace_check.py`: check a `romtrace` log for dropped reads. `rom_trace_classify.py`: classify ROM reads by splat segment.
- `tools/check_data_layout.py`: D02 check of adjacent variables in the ELF. `map_data_sizes.py`: static data of linked maps from the link map.
- `tools/golden.py`: golden frames (G01g), 10 scenes, pixel compare against `3ds/golden/*.png`, `--update` saves new references.
- `tools/phase_report.py`: tables from a `phase phasecsv` log.
- `tools/dedup_stubs.py`: drop stubs that a real file now defines (old). `tools/c01.sh`: C01 build helper (old).
- `tools/livelog.py`: live log over the network (TCP 17492). `tools/ftppull.py`: pull log and crash dumps over FTP (skills `pull-o`, `pull-n`).
- `build3ds/sheet.py`: contact sheet from shots. Other `build3ds/*.py`: sprite and shape helpers.

## Debug switches (grep `pm_debug_has` in 3ds/src)
- Start and input: `fast` (skip logos and the 30 Hz pad wait), `autoa` (press A), `freshsave`, `loadslot=<n>`, `padscript=<steps|@file>`, `padrand`, `padlog` (position every 2 frames), `taptest`.
- Warp (`pm_warp.c`): `testitem=<m|c|s>` (an item beside the player at scene frame 30), `warp=<map>:<entry>`, `story=<name|n>`, `preset=<name>`, `partner=<n>`, `sp=<n>` star points, `hp=<n>`, `battle[=<formation>:<stage>]`, `battlef=<n>`, `demobattle`.
- Run control: `smoke`, `smokeframes=<n>`, `tour=@file`, `tourfx=<n>` (transition for tour map changes), `turbo` (set by the script).
- Pictures: `shots` (PPM per 30 frames in `sdmc/3ds/PaperMario/shots`), `shotwin=<f>:<n>`, `shotmode=<mode>:<n>`, `shotskip=<n>`, `offdump`.
- Draw A/B: `nocomb` (no combiner plan path), `nocull` (no triangle culling), `nomix` (no blend or fog colour mix), `nooff` (no off-screen targets), `noprimz` (no prim depth), `rmoff` (old render mode handling), `nofallback` (no boot test triangle).
- Draw trace: `rmlog` (render mode changes), `drawlog=<f>:<n>` (one line per mesh chunk), `ddonly=<lo>:<hi>`, `ddverb`, `depthview=<1|2|3>`, `xtrace=<f>:<n>` (fills, texrects, state), `prevtest` (previous frame blur test).
- Checks: `ptrcheck` and `ptrtest` (N64 address assumptions), `romstrict`, `romtrace`, `romfull` (no packed ROM), `dataprobe` (map statics), `assets` (log asset loads), `scripts` (script dump every 120 frames), `faulttest`, `crashtest`, `crashtest_call`, `crashtest_audio`, `crashtest_audio_call`.
- Timing and log: `phase`, `phasecsv`, `phasegbi`, `stats` (gbi counters), `audiostat`, `pacestat` (pacing), `logstat`, `lognull`, `logflood` (10000 lines per frame), `noaudio`.
