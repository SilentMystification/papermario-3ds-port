## Code (PI6)
- pm_log.c: the writer thread now sends the socket first, then copies bytes into fb (log.txt, 128 KB) and cb (console, 8 KB). A new sink thread (prio 0x3F, writer core) writes fb every 100 ms, fsyncs once per second, and prints cb at most 10 times per second. Full fb: the writer writes synchronously (no line lost). Queue size unchanged (1024).
- pm_phase.c: pm_ph_frame_end copies the frame numbers into a 64-record ring. pm_ph_drain (writer thread) formats the phase lines (rsplit to gpusplit, and the csv lines). The game thread does no printf for them.
- pm_gpu.c: pm_gpu_hud copies the HUD rows only. pm_gpu_hud_flush (sink thread, 10 Hz) draws them.
- pm_port.h: declares pm_ph_drain.
- Not changed: the 2 s summarize (sorts, several ms every ~2 s) and ps_step bucket lines still run on the game thread.
