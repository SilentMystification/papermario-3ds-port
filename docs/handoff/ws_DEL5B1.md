## Facts (code read, main e3d2f6523b and its nd_gfx_tab.c)
- FACT every device v1 table is a moved particle list: flags NDG_F_PARTS | NDG_F_MOVED, list = &ndd_<name> (nd_gfx_conv.c:160, :179, :1008-1011). The device index has 182 of them (nd_gfx_tab.c `nd_gtab_n = 182u`). So the `nd_ops_run(t->list, ...)` arm of nd_parts_run (nd_walk.c:469, :519) never runs.
- FACT a v1 parts table is the list in unit order: NDG_VTX a = n, b = v0, p = the Vtx address; one NDG_TRI per triangle (a TRI2 unit gives 2), slots = index / 2; sync and no-op units give no op (nd_gtab.h:13-19, nd_gfx_conv.c:97). The entry units hold the same words: VTX w0 = n << 12 | (v0 + n) << 1, w1 = the same Vtx address (nd_gfx_tab.c ndnu_ arrays). t->nvtx is the sum of the load counts (nd_gfx_conv.c:97).
- FACT NdNDev fl bit 0 is the state-only flag. Its readers: nd_gtab.c:121 (`fl = nt->fl | 2u`, then `fl &= 1u`), nd_gtab_test.c:567. Bits 2 and 16-31 are free.
