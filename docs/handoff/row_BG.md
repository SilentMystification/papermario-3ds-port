# Rows BG1 and BG2: background image faults

Two agents, one per row. Both read how the background is drawn first, because the two faults can share one cause. Shared notes file: docs/handoff/agent_bg.md (each agent edits only its own section; findings that touch the other row go there AND go to the other agent by SendMessage).

## How the background is drawn (read first, both rows)
src/background_gfx.c gfx_draw_background (L336): the map background image is drawn in horizontal strips (texture rectangles, each strip a tile load of a few rows, scrolled by the camera yaw). The lists are written into the frame heap, so they run on the walker (SGEN skip class "inline words in the frame heap"). Walker side: texrect and tile load handling in 3ds/src/pm_gbi.c (grep G_TEXRECT, G_LOADBLOCK, G_LOADTILE, G_SETTILESIZE), texture slots in 3ds/src/pm_tex.c (strip keys, the TEXSTALE checks: grep pm_tex_stale_chk). Write in agent_bg.md: strip height in rows, tile size words, how a strip gets its texture slot, the texrect s/t and dsdx/dtdy values.

## Oracle plan for BG1 + BG2 (2026-11-06, Opus, from src/background.c and the texrect path; not yet confirmed)
User (O3DS and Azahar): a thin tall vertical rectangle, top-left, attached to the top edge, flickers when the camera scrolls; a garbled line near the top in most scenes. Draw: one CI8 296x200 bind (512x256 GPU, WRAP); bg_sky_rows: 2 row groups x 2 rects (left rect from s = 296-xOff, right rect from s = 0 at minX+xOff); bg_texrect adds +-296 copies in wide; bg_emit zooms every edge by 6/5 about x=640 (quarter px) when bg_zoom (the sky starts at screen row 0, so the strip touches the top). Zoomed edges are fractional (main left edge game -17.5); the split column crosses game x 0 near xOff 14-15.
Ranked causes: 1 F07-7 in pm_gpu.c pm_gpu_tex_rect (and RECT tex_raw_rect): a rect whose first pixel is exactly 0 is stretched to screen x 0 with s extrapolated 40 px back, a last pixel 319 to 400; in the zoomed sky those are not the sky edges (the copies already cover wide): smear or padding for a few xOff values, so it flickers top-left over the sky height. 2 gbi_texrect (pm_gbi.c ~4418) `xl/4` and `xh/4` truncate toward zero (wrong for negative edges, needs floor) while the texture span uses the fractional width: 1 px gap or texel jump at the seam. 3 the inclusive +1 edge or the zoom reaches s 296 / t 200 (padding): the BG2 garbled line at the row-group boundary (screen row (h-y0)*6/5) or t1 = 200. 4 copies zoomed after the shift (period 355.2 px): 1 px overlap or gap.
Measurement (one run, bg_flicker_mac00, frames 115 to 155, seams at 123 and 149): new switch `bgedge` in pm_gpu_tex_rect where F07-7 extends a rect: log `bgedge f%u x0 %d x1 %d xa %.1f xb %.1f s0 %.3f>%.3f s1 %.3f>%.3f`. Run with bgrect, bglog, bgedge, a shot every frame. Crop screen x 0..80, y 0..120 (PPM rotated: transpose ROTATE_90), note the strip columns per frame, map them to the logged rects (screen x = game px + 40 in wide). Strip frames = bgedge frames: cause 1. Columns covered by no rect: cause 2. Covered by a rect whose s or t reaches 296 or 200: cause 3. Covered by two rects with different s: cause 4. BG2: screen row of the garbled line vs yl/yh of the 2 row groups.
Fixes: 1 the sky skips F07-7: background.c (TARGET_3DS) wraps the bg_sky_rows calls in G_NOOP tag words (unique w1); the pm_gbi.c G_NOOP arm sets and clears a static and calls a new pm_gpu_rect_noedge(int); pm_gpu_tex_rect (and tex_raw_rect) skip the F07-7 block while set. 2 gbi_texrect COPY mode: px0 = (xl + 3) >> 2, px1 = xh >> 2 (arithmetic shift), s0 += dsdx * (px0*4 - xl) / 4 / tw, width px1 - px0 + 1; same for y (non-negative multiples of 4 unchanged, so HUD and menus unchanged). 3 COPY mode clamps s1, t1 to the tile end for the sky NOMASK tile (or bg_sky_rows ends each rect one texel short when zoomed). 4 bg_texrect zooms the main rect once and places the copies at +-(296*6/5) rounded the same way.
Gate: bg_flicker_mac00 frames 115 to 155 have no strip in the crop and no bgedge line on a sky rect; BG2 no garbled row at mac_00, mac_01, sbk_56; byte-equal pause menu and one non-wide scene (shared draw code); then a console push, the user walks left and right at mac_00 -57 0 76.
