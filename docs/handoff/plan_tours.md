# Plan TOURS: map tour, boss battle tour, perfect action cheat (oracle 2026-11-08, base nds1 5c84d16e7)

## User requirements (2026-11-08)
- Map tour: every map in ONE game session (no reboot), Azahar bench and console prof push. Fixed seed at each warp.
- A prof window opens after the map load settles and closes before the next warp: no window holds two maps. Time per warp: one setting (`tourtime=<s>`, default 4 s).
- The full tour finds the laggy maps. Curated list = laggy maps plus 2 warps per area. The curated tour is the epic-end "everything is good" check; the full tour runs only when the user asks.
- Battle tour: every boss (33, pm_boss_table.h) in one session, a few A presses each, fixed seed, cheat `cheats=action,hp`.
- Cheat "Perfect action commands" (Cheats tab, default Off): Mario AND partner actions, AND guard/block timing (user answers). Off unless the tab row or `cheats=action` sets it.
- Full tour story: one value, `story=ch0_toad_town` (user answer).
- Spot per map (user 2026-11-08): Mario warps to a central spot with the most content on screen, not inside a building, and stands ON the surface (not above or below it).

## Design
- Words: `tourlist=all|curated|@file` (all = built from gAreas, no tst_, the spot of the map from the compiled table pm_tour_spots when it has the map, else entry 0; curated = compiled list pm_tour_curated, items with the same spots; the console has no SD file, so no run-time read of spots.txt), `tourtime=<s>`, `battletour=all|i,j,..`, cheat token `action`.
- Map state machine in pm_warp.c (done, TOUR1): WARP (gRandSeed = TOUR_SEED; tour_step) -> SETTLE (60 frames after the map is in; tour10_det shows no load hitch in the window after it) -> MEASURE (pm_ph_window_open) -> CLOSE (pm_ph_window_close: line `prof f<n> w<n> tour <i>/<n> <map>:<entry>`, then the pf_report lines). A map or mode change in MEASURE closes the window early (`tour: scene left`). Event lines (pass in prof mode): `tour: window <label> open f<n> rng <seed>`, `tour: at <map> y <y>`, `tour: done items <n>`. The warp= map is not an item. In tour mode pm_phase's 300-frame report and scene drop are off. tourshot=<k> below 60 keeps the shot cost out of the window; det audiohash and census frames (every 120/300 frames) still land in some windows. The other tour scenarios (mac01t family, mapchange_hud*, golden_multi*, wcen_golden, mem_reenter) now change map later (60 + tourtime frames per map, was 40): their shot frames need a new pick before their next run.
- Battle state machine (done, BT1): LAUNCH (world launch pm_boss_launch, gRandSeed = TOUR_SEED; the launch sets hasActionCommands, kept and restored like HP/FP) -> WAITBATTLE (GAME_MODE_BATTLE, then TOUR_SETTLE frames; 20 s timeout -> `battletour: <label> FAIL (<why>)`, next) -> PLAY (window, tourtime; autoa from the scenario) -> END (boss_end: battle menu windows cleared, BATTLE_STATE_END_BATTLE) -> RESTORE (boss_restore_tick, then 10 world frames) -> CLOSE (`battletour: <i>/<n> battle:<boss> closed`). Window line `prof f<n> w<n> tour <i>/<n> battle:<boss>` (spaces as _), ingest kind battle. End line `battletour: done items <n> fail <k>`. A debug battle start clears the damage popup slots (a forced end leaves freed effects in them). Boss and battle table rows whose battle stage is not in the area's StageList carry no stage part and start on the battle's own stage (Jr. Troopa 03 to 07; their old stage 00 kmr_02 has no shape in the ROM and hung load_asset_by_name). With tourtime=4 only Mario's turn runs; tour_battle_cheat (Goomba King, 20 s) covers the partner command and the guard.
- Cheat: bit CHB_ACTION (pm_dbg_game.c), tab row, `cheats=action`. `#ifdef TARGET_3DS` hook at the end of action_command_init_status: autoSucceed = true (showHud unchanged), Mario and partner; one line in check_block_input for a perfect guard.
- Spots (done, POS1): `python 3ds/tools/tour_spots.py` writes 3ds/tours/spots.txt (map:0@x:y:z, map:0 for 10 maps without a spot) and 3ds/tours/spots_report.txt (score, content counts, roof clearance, reason) from the map hit and shape files. Candidates are 16-unit grid points on the floor linked to entry 0 (steps up to 12 link). A spot needs flat neighbours, no wall across them, no geometry 40 to 600 above, and a camera view of Mario: the camera zone under the spot (hit file zone section, CameraControlSettings) gives the view direction and boom, and no model triangle may cut Mario-to-eye. Score = view-box content (models, entities, NPCs) over the map best, minus 0.5 x distance to the floor centre. Fallback order: outdoor and seen, indoor and seen, outdoor, indoor (reason in the report). An entry script that holds the camera (kmr_20 entry 0 at ch0) still frames the map from its own spot; the tool cannot see that. Host test: tour_spots_test.py. At run time the WARP state snaps y from y+200.
- Perf DB: bench.py ingest reads the tour lines, one window record per map with tour_idx and kind (map/battle). Tags tour_full, tour_curated, tour_battle. `bench.py tour-report <run>`: one row per map (ft_ms, wk, o34, o34% = o34 over the clean frames of the window, gbi, draws, tris), ranked by ft_ms then o34. Azahar ft_ms is held at the 30 fps lock (all maps near 33.3 ms), so the Azahar ranking is weak; the console run decides.
- Curated: `bench.py tour-curate <run> [--slow-ms 33.3] [--top 20] [--per-area 2]` -> 3ds/tours/curated.txt (header: source run, build, rule). Rule: ft_ms over slow-ms (top N), plus the top M maps of each area (area = map prefix), rank ft_ms then o34. Seed: the Azahar tour10_det ingest (run 25284); replace after tour_full_prof. `python 3ds/tools/gen_tour_lists.py` writes 3ds/src/pm_tour_lists.h (spot table from spots.txt, curated list). Generated by hand-run, committed; CMake does not run it.
