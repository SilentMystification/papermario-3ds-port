## Oracle plan for RECT-1b (2026-11-06, Opus; patch scratchpad rect1ab_clean.patch)
White = TEXTURE0 sample 1.0 or TEX0 not active (stage 0 TEX0*PRIMARY, vertex colour ffffffff). Positions are right, so prog4, attr4, gring, pal[0] are right. Ranked causes: 1 GPU reg 0x80 (texture unit enable) off: nd_emit.c nd_emit_draw writes 0x80 only when !sh->cfg_valid || sh->cfg != en; u.force rewrites the unit block, not 0x80; C3Di_UpdateContext in nd_native_submit can write 0x80 with citro3d unit 0 = NULL (pm_tex.c C3D_TexBind(0, NULL)) after the shadow check. 2 unit 0 samples another image: the close reads pm_tex_native_unit0 (slot at the close), not rect_tex (slot when the rect was queued). 3 uvso uniform stale (pm.v and pm4 share float uniform regs; the ndn_sh.uni shadow says current). 4 TEV words other than stage 0 (0xC4, stages 1-5, 0xE0/0xFD). 5 texcoord attribute format regs 0x201/0x202/0x2BB stale (bound/buf_cur caches).
Measurement (one run, mac_01): cold noinline `cb_regdump(const char* tag)` in pm_gpu.c, switch `rectreg=<frame>`: parse the GPUCMD buffer (GPUCMD_GetBuffer) from the last offset to the current into a static u32 reg[0x300] shadow (param word then header: id bits 0-15, mask 16-19, extra count 20-27, consecutive bit 31, pad to 8 bytes; track 0x2C0 index and 0x2C1 writes as float uniforms; restart at 0 after a split). One line per call: tag, 0x80, 0x81-0x85, 0x8E, the 6 TEV stages, 0xE0, 0xFD, 0x100-0x107, 0x200-0x204, 0x2BB-0x2BD, 0x242, 0x24A, 0x04F-0x056, 0x064, the uvso uniform, pal[0] row 0, bound, rect_tex, pm_tex_cur_idx(), first 8 bytes at u0.addr vs pm_tex_cur_data. Call 'cpu' after the C3D draw in flush_draw_cpu (rect_2d && tex), 'nat' after nd_native_submit in nd_raw_native (rect_2d && tex). Switch `rectalt`: tex_raw_rect returns 0 on every second call, so one frame has both. The first register that differs names the cause.
Fix per outcome: 0x80 bit 0 off at nat: nd_emit_draw enable condition `|| t->force` (or ndn_sh.cfg_valid = 0 after C3Di_UpdateContext when its dirty bits include 0x1800000). Unit regs or bytes differ: nd_raw_native for rect_2d takes the unit words from the slot of rect_tex at queue time (store it in the batch). uvso differs: nd_native_submit clears ndn_sh.uni_valid and pal_valid on the first native draw after a citro3d draw. TEV differs: nd_tmpl.c nd_tev_build rect_2d combine 2 matches the CPU TEV setup. Attribute regs differ: clear bound and buf_cur after a citro3d draw. All equal: texture memory flush (pm_fl_dc of the slot).
