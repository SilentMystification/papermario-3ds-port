## Oracle plan for RECT-1b (2026-11-06, Opus; patch scratchpad rect1ab_clean.patch)
White = TEXTURE0 sample 1.0 or TEX0 not active (stage 0 TEX0*PRIMARY, vertex colour ffffffff). Positions are right, so prog4, attr4, gring, pal[0] are right. Ranked causes: 1 GPU reg 0x80 (texture unit enable) off: nd_emit.c nd_emit_draw writes 0x80 only when !sh->cfg_valid || sh->cfg != en; u.force rewrites the unit block, not 0x80; C3Di_UpdateContext in nd_native_submit can write 0x80 with citro3d unit 0 = NULL (pm_tex.c C3D_TexBind(0, NULL)) after the shadow check. 2 unit 0 samples another image: the close reads pm_tex_native_unit0 (slot at the close), not rect_tex (slot when the rect was queued). 3 uvso uniform stale (pm.v and pm4 share float uniform regs; the ndn_sh.uni shadow says current). 4 TEV words other than stage 0 (0xC4, stages 1-5, 0xE0/0xFD). 5 texcoord attribute format regs 0x201/0x202/0x2BB stale (bound/buf_cur caches).
Measurement (one run, mac_01): cold noinline `cb_regdump(const char* tag)` in pm_gpu.c, switch `rectreg=<frame>`: parse the GPUCMD buffer (GPUCMD_GetBuffer) from the last offset to the current into a static u32 reg[0x300] shadow (param word then header: id bits 0-15, mask 16-19, extra count 20-27, consecutive bit 31, pad to 8 bytes; track 0x2C0 index and 0x2C1 writes as float uniforms; restart at 0 after a split). One line per call: tag, 0x80, 0x81-0x85, 0x8E, the 6 TEV stages, 0xE0, 0xFD, 0x100-0x107, 0x200-0x204, 0x2BB-0x2BD, 0x242, 0x24A, 0x04F-0x056, 0x064, the uvso uniform, pal[0] row 0, bound, rect_tex, pm_tex_cur_idx(), first 8 bytes at u0.addr vs pm_tex_cur_data. ## Oracle plan 2 for RECT-1b (2026-11-06, Opus; result: registers equal; rectalt right, native-only white; native-only frame 200 had ONE native close)
rectalt is right because each CPU rect calls rect_begin, which flushes: every native batch holds one rect. Native-only gave one close for the frame: rect_raw_open merged all textured rects into one draw with one unit 0 and one uvso. The merge key (ec, rect_z, rect_tex = pm_tex_cur_idx() at open, fz, uvso) does not stop rects with different images, or the close (nd_raw_native -> pm_tex_native_unit0) reads the slot current at the close, not the slots of the queued rects.
Causes: 1 (high) wrong merge: rects of different textures (sky, ground) merged into one close that samples one image; the CPU batch is kept apart by flush hooks that test nverts, a raw batch has nverts 0 and gni > 0 (grep the texture-load and tile paths that call flush / pm_gpu_rect_sync on `nverts`). 2 state read at close time (a later non-rect op already loaded another texture or combine). 3 per-rect vertex data wrong (sc per rect, or pm_gpu_gvtx_load returned -1 on a full ring and rect_raw_quad does not check it). 4 texture cache or C3D dirty bind: rejected.
Measurement (native-only, mac_01 f200, rectreg; patch scratchpad s6/rect1ab_plus_diag_mine.diff): dump every native close, no cap: index, rects since open, gni, rect_tex at open, pm_tex_cur_idx() at close, u0.addr, dim, type, 8 texel bytes at u0.addr, close reason (rect_raw_open break, rect_begin, pm_gpu_rect_sync, other flush). Per rect: s,t shorts read back from gring b..b+3, and the queue-time slot. Cause 1 confirmed: one close holds rects with different queue-time slots. Then one shot with switch `rectnomerge` (rect_raw_open never merges): right picture confirms the merge.
Fix: cause 1 or 2: rect_raw_open stores the NdUnit of the rect (pm_tex_native_unit0 at queue time) and the plan/prim key in the batch; a merge needs the same unit words (addr, dim, type, param) and plan key; nd_raw_native's rect branch uses the stored unit; every texture or state change that flushes the CPU batch also flushes a raw rect batch (`nverts > 0 || gni > 0`, or rect_open). Cause 3: check b < 0, flush and retry once or take the CPU path; sc per rect. Second finding (same row): clear the CPU sh_uvso shadow in nd_leave_native / raw1_reset with the other pm4 uniform shadows.
Gate: native-only mac_01 right by eye; rect line native > 0, cpu 0, merged > 0; census wd camera_render and 2 background lists 0; mac_01 byte-equal against norectraw; mac_00 sky, pause menu, toad_house_menu by eye. Then the BG F07-7 note applies to tex_raw_rect.
