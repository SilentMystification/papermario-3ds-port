# Paper Mario 3DS Port

This is a WIP port of the original Paper Mario for the N64 to the 3DS. 

It is forked off of the original decomp:
https://github.com/pmret/papermario

The goal is to port the game as accurately as possible until performance limitations are hit. 

## AI Disclosure
This project was developed with the assistance of Claude, Cursor and AI tools in general. My personal goal is gaining profficiency with new tools and just making something neat in general. 

This being said, the primary goal here is functionality. This disclosure is made because I want to be up front with how this was created.  

## Features
- 60FPS gameplay with interpolated frames
- Widescreen support 

## Supported Platforms
O3DS, N3DS

Performance is tight on the 3DS family, especially the Original 3DS. 

Performance Target for O3DS 
- is parity with the N64, 30FPS with occasional frame skip. 

Performance Target for N3DS
- Mostly locked 60FPS gameplay with widescreen enabled.
